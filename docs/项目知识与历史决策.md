# CYM 项目知识与历史决策

这是截至 2026-11-16 根据本项目对话、已有设计和代码整理的维护指南。用户的新要求优先；已上线状态、账户身份和问题是否仍存在，均需重新核实。早期设计里的 UI 颜色、部署状态等可能已过时。

## 项目定位与用户偏好

- 在 `D:\work\cym` 独立实现 mskj 的本地商圈模式；不导入原项目历史数据。用户端为 H5，后台独立，安卓首版是加载现有 H5 的 WebView 安装包；iOS 不在最初范围内。
- 不保留原系统的代理、VIP、通证、权益值、贡献值以及旧聊天室、语音功能。后续明确提出的新功能应单独按最新需求处理；当前工作区已有客服相关未提交修改，不应因历史排除项误删。
- 风格参考拼多多，红色、紧凑、减少空白；首页展示指定横幅及“本地商圈｜让每一个消费者成为消费商”。H5 和后台都要在手机窄屏可用。避免让管理员输入 JSON 等程序格式。
- 用中文说明变更和验证结果；用户倾向直接完成已授权工作，并曾要求代码推送 `git@github.com:fancrystal/cym.git`、部署到现有服务器。对新任务确认授权范围及工作区状态，勿把历史部署授权扩大到无关操作。

## 商圈与账户规则

- 系统根账户用于承接商圈收益，不可购买、邀请或作为普通用户上级；无上级普通用户不是系统根账户。管理员与商圈账户是不同身份。历史对话中的手机号出现过更正，遇到具体账户操作应查询当前记录确认，不凭旧文字覆盖数据或密码。
- 首批普通用户可通过后台创建，设置手机号、用户名、密码、可选上级和初始产品券；后续可通过商圈邀请码或二维码注册。注册时提供支付宝账号。团队页显示累计收益、分组和本人复购次数，个人页也显示复购次数。
- 每次购买一件；第 N 次购买奖励符合购买次数资格的第 N 层上级，否则归系统根账户。购买、库存、账户余额、复购次数、奖励和流水必须在事务内一致；购买、充值、转赠、提现的重复请求要防重。金额用分或数据库 DECIMAL 处理，避免浮点结算误差。
- 产品券转赠按整数原额到账，校验登录密码及余额；不恢复旧权益值校验。商品分类共用 `packages/shared/categories.js`，历史“健康食品”和误写“保健适配”需兼容归入“保健食品”；已有水果、蔬菜、内蒙专购等分类。
- 后台商品管理支持本地上传封面及详情图、表单式款式、分类和上下架；订单页面展示商品图。收货地址只要求收货人、手机号和完整地址文本，不要求省市区选择。到货通知有未读红点，用户收到通知后确认收货。

## 提现与隐私

- 提现从产品券余额扣除，最低 50、必须为 50 的整数倍，手续费 6%，1 券兑 1 元；例如申请 100 券，到账 94 元。申请时先扣券，后台审核后线下转支付宝；驳回待审核申请退券。
- 管理员须能看到完整收款人和支付宝账号以便转账，默认脱敏可通过操作展开，但展示应明显易懂。转账后上传截图、填写转账记录并标记完成；用户提现记录需显示缩略图，可点开原图。截图是私有文件，须校验归属与权限；加密密钥及上传目录必须保留。

## 工程与运行

- `packages/h5` 为 Vue H5，`packages/admin` 为 Vue 后台，`packages/backend` 为 Express/MySQL API，`packages/shared` 为共享业务代码；安卓工程在 `packages/android`。README 记录本地启动和测试方式。
- 常规检查：`corepack pnpm test`、`corepack pnpm --filter @cym/h5 build`、`corepack pnpm --filter @cym/admin build`。普通测试会跳过真实 MySQL 集成项，不得把跳过项称为通过；需要时仅对本机测试库单独启用集成测试。安卓修改按工程 README 运行 Gradle 测试与构建，并区分模拟器和真机结果。
- 服务器、SSH、发布和回滚参见 [服务器与 SSH 运维](服务器与SSH运维.md)。仓库 `.env` 和安卓签名文件均属于本地私密材料，不应提交或泄露；不要假设某个口头提到的初始密码仍然有效。

## 已知历史检查结果与经验

以下为历史观察，修改前先重新复现，不能假定当前依然存在：

- 2026-11-12 检查发现向不存在的订单发送到货通知可能返回成功；H5 缺少完整订单详情和收货地址；订单图读取商品当前封面，后续改封面可能影响旧订单显示。
- 安卓模拟器曾无法完成 App Links 域名自动验证；包内接收邀请链接、扫码入口与系统自动打开链接是不同验证项，真机结果未确认。
- 微信分享已设置 OG 标题、简介与首页横幅封面。2026-11-15 用户实测部分微信链接卡片没有图片；服务器检查未看到微信抓取新版封面。OG 不保证微信显示图片，粘贴链接和微信内菜单分享是不同场景；可能存在微信缓存，具体原因未确认。需要微信 JS-SDK 时，先核实公众号接口权限和域名配置，不要索取或在聊天中暴露 AppSecret。
- 管理员“查看收款信息”曾是在按钮下方展开完整信息，用户误以为按钮只是位移；检查实际页面，不要将默认脱敏误解成管理员无法查看。
