# Android 商圈 App 实施计划

**目标：** 交付可安装的独立安卓 App，安全加载现有商圈 H5，并支持邀请扫码和提现截图原图。

**架构：** Kotlin 原生 WebView 仅加载 `https://cym.green`，通过限定来源的 WebMessage 触发扫码和分享；H5 保留现有 token 与业务，邀请链接及图片预览由 H5 兼容处理。

**约束：** 不引入聊天、语音或自动付款；使用独立签名，禁止提交密钥；线上 H5 与后台数据保持独立。

1. 在 H5 为商圈邀请链接和原图查看编写验证，支持 App 冷启动及前台接收邀请链接。
2. 建立独立 Android 工程、域名校验和原生壳测试；实现扫码、链接、返回、文件选择、网络错误及权限控制。
3. 在本地使用 Android Studio JDK、SDK 和 Gradle 构建测试版及独立签名正式 APK，测试签名、启动和邀请路径；可用模拟器时执行设备验收。
4. 以独立路径发布 H5 更新、App Links 文件与 APK 下载页；先准备备份和回滚，验证原商圈及 mskj 状态。
5. 更新 README、记录安装包和签名备份方法，提交并推送非敏感代码；如无真实手机，明确未完成真机验收。
