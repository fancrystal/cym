# 本地商圈实施计划

**目标：** 在独立数据库上交付本地商圈 H5、管理后台和 API，并支持与 mskj 同机部署。

**架构：** Vue 3/Vite H5 与后台分别使用同源 `/api` 访问 Express；MySQL 保存账户、产品券、商圈关系、商品与订单。以已确认的设计文档为范围和验收依据。

**技术：** Node.js 20+、pnpm 10、Vue 3、Vite、Express、MySQL 8、Vitest。

## 全局约束

- 只保留产品券及商圈业务；不迁移历史数据；H5 与后台必须适配 320px 及以上窄屏。
- 保持原商圈收益归属与购买完成状态；转赠去除权益值，整数原额到账。
- 使用 `cym.green` 和 `admin.cym.green`；部署前核对端口和现有服务，隔离数据库、进程、文件及站点。
- 密码只以哈希保存，初始化凭据通过运行时安全输入传入，不写入仓库。

## 任务及验收

1. **基础和规则**：建立 workspace 与后端测试入口；移植收益归属的纯业务规则，测试第 N 层、资格不足、缺失上级和关系环。交付可独立运行的规则测试。
2. **数据库及身份**：创建新库迁移、事务辅助、管理员和用户登录、邀请码注册、根账户初始化及首批用户操作说明。测试邀请码绑定、根账户限制和权限隔离；使用真实 MySQL 验证迁移。
3. **产品券与购买**：实现充值、流水、整数转赠、商品、地址及商圈购买。测试并发、幂等、余额、库存、精度、归属和失败回滚；在 MySQL 中对账。
4. **H5**：复用并简化源 H5，提供登录、扫码链接注册、商圈、商品详情、团队、产品券、地址及订单，去除旧体系入口。测试邀请链接、购买和转赠，运行构建并在多个窄屏视口检查。
5. **后台**：复用并简化用户、商品、订单、到货通知和商圈统计；验证权限、充值、商品配置、统计对账及窄屏菜单和操作。
6. **交付与部署准备**：编写独立服务、环境变量、Nginx、初始化、备份恢复和部署说明；构建两端并进行完整业务联调。实际部署前检查 DNS、证书、现有站点、端口及备份。

每个任务先编写针对行为的测试并确认失败，再实现和运行相关测试；任务交付前检查与设计文档逐项一致。无真实数据库时不得声称完成数据库或端到端验收。
